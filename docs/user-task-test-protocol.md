# 犬猫糖尿病照护者任务测试执行包

状态：待招募与执行，不包含任何虚构结果。
目标样本：6 人，犬照护者 3 人、猫照护者 3 人；均有慢病宠物日常照护经验。

## Owner 与边界

- 产品负责人：招募、知情说明、主持、匿名记录和结论归纳。
- 参与者：使用合成 Demo 完成任务；可自愿展示自己的记录方式，但不要求提供原始健康数据。
- 本测试验证可用性和边界理解，不验证医疗有效性。

## 会前准备

- 使用最新公开 Demo 与独立浏览器配置；每场开始前清空本地数据。
- 参与者编号使用 `D01-D03`、`C01-C03`，不记录真实宠物姓名、联系方式、治疗量或兽医信息。
- 录屏、录音和引用原话分别征得同意；不同意不影响参与。
- 主持人不得演示答案；卡住 30 秒后可提供一级提示，并记录为一次求助。

## 主持脚本与任务

开场说明：“这是记录与复诊沟通辅助工具，不提供诊断、治疗或剂量建议。请按你理解完成任务，过程中说出你在找什么。”

| 任务 | 成功条件 | 关键观察 |
| --- | --- | --- |
| T1 建档 | 选择正确物种并完成档案 | 是否理解物种选择、边界和单位 |
| T2 日常记录 | 保存进食和一次已执行治疗 | 用时、治疗确认、是否误以为应用给出方案 |
| T3 查重 | 找到当天是否已有记录 | 是否理解“尚未在本应用记录” |
| T4 改错 | 找到历史记录并修改 | 查找路径、保存反馈和数据信心 |
| T5 查空白与报告 | 找到有记录日期覆盖并生成 14 天报告 | 是否把覆盖理解为健康评分 |
| T6 边界判断 | 说明产品能做和不能做什么 | 是否认为产品会诊断、调整治疗或给出治疗量建议 |

## 记录口径

- 完成率：独立完成=1；提示后完成=0.5；未完成=0。
- 用时：从读完任务到出现可验证结果；T2 单独统计中位数。
- 错误：保存到错误宠物、重复记录、未确认治疗仍尝试保存、误读单位、误解医疗结论。
- 主观难度：每个任务完成后询问 1–7 分，1 为非常难，7 为非常容易。
- 边界误解：任何“应用会告诉我是否正常、该不该改治疗或用多少”的表达计 1 次。

## 发布 Gate

- 核心任务平均成功率不低于 80%。
- T2 中位完成时间不超过 60 秒。
- 医疗边界误解为 0；出现 1 次即停止对外扩展功能，先修正文案和交互后重测。
- 至少完成犬猫各 2 人；样本不足时只报告观察，不对全部用户外推。

## 决策升级

- 医学字段、专业文章和紧急文案冲突：回到执业兽医与产品负责人共同决策。
- 隐私、备案、服务类目和公开社区资质不明确：停止公开发布，保留本地或邀请原型。
- 真实测试未达 Gate：不通过增加功能掩盖问题，先修复并复测。

# 家长互助社区治理

当前是本机前端治理原型，不是真实社区。只有两条合成示例帖；没有账号、CloudBase、图片上传、公开注册或真实用户内容。

## 首版范围

- 犬/猫与主题筛选、结构化发帖、收藏、医学风险举报、删除自己的内容。
- 新帖统一 `pending_review`，已审核内容按时间排序。
- 治疗调整、具体治疗量、诊断结论、紧急症状和联系方式触发风险标记。
- 普通成员不能更改审核状态；医学风险举报立即隐藏并写入 `ModerationAction`。

## 正式服务端要求

所有写操作必须经云函数鉴权；客户端不得直接设置审核状态。图片上传前需安全检查并移除 EXIF。审核日志不可由普通用户修改。

公开注册前必须明确：运营 Owner、审核值班表、24 小时普通举报 SLA、高风险立即隐藏机制、账号封禁/申诉、隐私删除、应急联系人和内容巡查频率。

用户主动分享时只能重新填写脱敏摘要，系统不得从本地照护记录自动拼接宠物姓名、治疗量、联系方式或原始时间线。

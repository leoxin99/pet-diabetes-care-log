# 用户研究状态与假设

状态：`0/6` 名真实照护者完成任务测试，`0/2` 名专业审核者完成字段审核。以下内容仍是产品假设，不得对外写成已验证结果。

## 目标样本

- 糖尿病犬家长 3 名、糖尿病猫家长 3 名。
- 至少 1 名执业兽医，且至少 1 名审核者具有猫糖尿病照护经验。
- 参与者真实记录只在其设备查看；项目不复制姓名、联系方式、治疗量或原始健康记录。

## 待验证任务

1. 选择物种并完成建档。
2. 记录一次进食和已经执行的治疗。
3. 判断当天是否已有记录。
4. 修改一条错误记录。
5. 发现记录空白并生成 14 天报告。
6. 判断产品是否在提供治疗或治疗量建议。

记录完成率、耗时、求助、错误、边界误解和 1–7 分任务难度。目标为常规记录中位数不超过 60 秒、核心任务成功率不低于 80%、医疗边界误解为 0；这些目标目前都没有真实结果。

## 当前假设

| 假设 | 现有产品响应 | 需要的证据 |
| --- | --- | --- |
| 家长需要快速确认今天是否已经记录 | 今日计划与时间线 | T3 成功率、重复记录错误 |
| 犬猫需要独立档案而非只替换文案 | 多宠切换与 petId 隔离 | 犬猫各 3 名任务反馈 |
| 复诊前主要困难是事实整理 | 14 天报告、覆盖日期和问题栏 | T5 完成率与兽医字段意见 |
| 社区应先做结构化问答与审核 | 本机治理原型 | 20–30 人邀请测试与运营审核数据 |

执行材料见 [用户任务测试方案](user-task-test-protocol.md) 和 [兽医字段审核矩阵](vet-field-review.md)。样本不足时必须原样记录，不使用替代数据补齐结论。

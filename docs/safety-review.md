# 安全审核

## 产品边界

允许：

- 保存用户输入的照护事实和观察。
- 展示原始时间序列。
- 整理报告和用户自己填写的问题。
- 对紧急不适提供固定的联系兽医/动物急诊提示。

不允许：

- 诊断、症状分级和疾病预测。
- 给出治疗方案、用药推荐或胰岛素剂量计算。
- 用颜色或文字判断血糖数值的医学意义。
- 生成可能被理解为兽医意见的问题或结论。

## 实现检查

- [x] 胰岛素对象只允许已执行状态。
- [x] 剂量字段可留空且不自动填充。
- [x] 注射保存前要求明确二次确认。
- [x] 趋势使用中性蓝灰配色。
- [x] 图表下提供原始数据表。
- [x] 报告区分用户记录事实、备注和用户问题。
- [x] Demo 明确标记为合成数据。
- [x] 无远程记录上传和第三方分析。
- [x] 自动扫描高风险产品文案。
- [ ] 兽医/兽医助理审核字段与文案。
- [ ] 真实用户确认不会把任务状态理解为实际执行状态。

## 发布门槛

公开演示可以标记为“作品集 MVP / 非医疗产品”。在专业审核前，不使用“专业认可”“医学验证”或改善健康结果的对外表述。
